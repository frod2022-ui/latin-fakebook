How to add your own songs

Typing a chord chart

Press Add song. Type the chords bar by bar between bar lines:

| Am7 | D7 | Gmaj7 | % |

%Play the bar before again
| C G7 |Two chords share the bar (two beats each)
| C / F G |One chord per beat; / keeps the chord going
|: … :|Repeat a section. Endings: |1 … :|2 … |
A: | … |A section label at the start of a line
ChordsC Cm C7 Cmaj7 Cm7 Cm7b5 Cdim7 C7b9 C7#11 C9 C13 Csus4 C6/9 C/E

Adding a melody (optional)

The melody is typed in ABC, with letters for notes: C D E F G A B from middle C up, c d e an octave higher, z for a rest. A number after a note makes it longer (C2), / shorter (C/). Start with lines such as M:4/4, L:1/8 and K:G. Chords can go in quotes right in the melody: "Am7"A2 c2 "D7"d4 — then you don't need a separate chord chart.

Opening files

Import opens ABC files (.abc, with chords in quotes), chord charts (.txt), MusicXML (.xml, .musicxml, .mxl – chord symbols are read too) and MIDI (.mid – chords are guessed from the accompaniment).

Your songs stay on this device

Songs you add or import are saved only inside this browser on this device. Nothing is uploaded anywhere. Use Back up my songs in the song list to save a copy as a file, and Import that file to bring them back or move them to another device.
